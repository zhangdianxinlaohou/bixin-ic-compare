# 比芯

比芯：芯片公司的照妖镜。当前覆盖东方财富半导体行业板块全部 188 家成分股，并补充库内其他算力与 IP 公司、台股矽力杰，以及第一批 15 家国际大厂，共 224 家。A 股和台股数据期为 2021Q1 至 2026Q3。

在线访问：<https://zhangdianxinlaohou.github.io/bixin-ic-compare/>

## 打开方式

这是一个纯静态网页，不需要后端、数据库或 Node.js。

1. 双击 `打开网页.bat`，或
2. 直接用 Chrome / Edge 打开 `index.html`。

如果希望通过 `http://127.0.0.1:4173` 访问，可以手动启动静态文件服务器：

```powershell
python -m http.server 4173
```

这个服务器只负责提供本地静态文件，不是应用后端。

如果需要单独发给朋友，请发送 `IC-Compare-单文件版.html`。它已经内嵌样式、数据、脚本和图表库，不需要同时发送其他文件。

小红书 / 手机分享版：直接打开 `xiaohongshu.html`，或发送单文件 `IC-Compare-小红书版.html`。手机版针对直板手机做了字号放大、横向公司卡片、底部三栏导航和搜索框防自动缩放处理，已检查 375、390、430 像素宽度。

需要上传到小红书小工具时，使用整理好的 `小红书小工具上传包` 文件夹；入口文件是其中的 `index.html`。同目录另有 `小红书小工具上传包.zip`，便于直接上传。

小红书图标与封面位于 `小红书品牌素材`：

- `icon-1024.png`：1:1 图标，1024×1024
- `cover-1200x1600.jpg`：3:4 封面，1200×1600

可编辑源文件位于 `小红书品牌素材/源文件`。

## 页面功能

- 搜索并添加公司，支持公司名、股票代码、行业分类和产品关键词
- 最多同时对比 20 家公司，搜索下拉框支持按分类完整滚动浏览
- 公司卡片展示产品矩阵、2025 年营收、净利润和研发强度
- 核心指标表支持「按年 / 按季度」切换，并可选择 2021–2025 年报或 2021Q1–2026Q3 的全部单季
- 近年表现支持年度 / 单季度切换
- 可自由选择最多 3 个曲线指标，每个指标独立成图
- 每张图可单独显示或隐藏任意公司，图表支持折线图 / 柱状图
- 新增营业收入增速、经营性现金流增速、净利润增速；季度视图可切换同比 / 环比，年度视图使用同比
- 公司颜色在卡片、表格和曲线中保持一致
- 支持 CSV 导出、对比链接复制和 URL 分享
- 桌面端、移动端响应式适配

## 指标覆盖

财务指标：

- 营业收入
- 毛利率
- 净利润
- 经营性现金流
- 研发费用
- 研发强度
- 账上现金

年度人员与研发指标：

- 员工数量
- 人均薪酬
- 研发人员数量
- 研发人员占比
- 研发薪酬（估算）
- 研发人员人均投入

员工、薪酬和研发人员数据只按年度披露，因此单季度视图不提供这些指标。

## 数据来源与口径

- 数据来源：东方财富公开财务数据接口
- 抓取时间：见页面底部与 `data.js` 中的 `meta.generatedAt`
- 季度数据由累计报表逐季差分得到单季值
- 如果上一季度关键字段缺失，则该单季值留空，不强行相减，避免出现虚假的负毛利
- 账上现金 = 货币资金 + 交易性金融资产
- 人均薪酬 = 支付给职工以及为职工支付的现金 ÷ 期末员工人数
- 研发薪酬按研发人员占比分摊现金薪酬，是估算值，并非年报单独披露口径
- 研发人员人均投入 = 研发费用 ÷ 研发人员数量
- 矽力杰（6415.TW）：财务数据来源为台湾公开财报数据，营收、利润和现金流按期间日均 TWD/CNY 折算，现金按期末汇率折算
- 矽力杰当前未能从结构化数据中取得研发费用、员工人数、人均薪酬、研发人员数量和研发薪酬，这些字段留空
- 国际大厂来自 SEC EDGAR XBRL 与台湾公开财报；ASML 和 STMicroelectronics 当前只接入年度核心财务，季度数据暂未接入
- 国际公司的人员、人均薪酬、研发人员数量、研发薪酬等字段多数没有结构化披露，页面留空

本工具不构成投资建议，正式引用前请回查公司年报。

## 文件结构

- `index.html`：页面结构
- `styles.css`：页面视觉与响应式布局
- `xiaohongshu.css`：小红书手机版专用排版
- `app.js`：搜索、对比表、指标选择、曲线图与导出
- `data.js`：209 家公司及 2021Q1 至 2026Q3 数据
- `global_data.js`：15 家国际大厂及 SEC / 公司披露数据
- `scripts/fetch_globals.py`：国际公司年度/季度财务抓取与汇率折算脚本
- `scripts/build_xhs.py`：生成小红书手机版及单文件版
- `vendor/echarts.min.js`：本地 ECharts 图表库
- `scripts/fetch_financials.py`：公开财报数据抓取与 `data.js` 生成脚本
- `打开网页.bat`：双击直接用默认浏览器打开页面

## 更新数据

在项目目录执行：

```powershell
python scripts/fetch_financials.py
```

脚本会重新拉取全部公司数据并覆盖 `data.js`。公司名称、产品标签、分类和描述维护在 `scripts/fetch_financials.py` 的 `COMPANIES` 列表中。
